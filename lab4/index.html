    Отчет по Лабораторной работе №4

    Сервис для управления школьной информацией

    В этой лабораторной работе создается сервис для управления информацией о преподавателях, учениках, классах и расписаниях, с возможностью аутентификации, оценки и редактирования данных.

    1. Аутентификация

    Настройка Axios

    Для настройки взаимодействия с сервером используется Axios с базовым URL и токеном аутентификации.

    • Базовый URL: все запросы к API отправляются по следующему URL: http://localhost:8000/auth/.
    • Токен аутентификации: для взаимодействия с защищенными эндпоинтами используется токен, который передается в заголовках всех запросов.

    Интерцепторы

    Используем интерцепторы для автоматической подстановки токена и обработки ошибок:

    1. Добавление токена: При каждом запросе к API автоматически добавляется токен из хранилища.
    2. Обработка ошибок: Если сервер возвращает ошибку (например, 401), происходит перенаправление на страницу логина.

    Регистрация (registerUser)

    • Отправляет данные пользователя (email, username, password) на эндпоинт auth/users/.
    • Проверяет совпадение паролей перед отправкой.
    • В случае успеха появляется сообщение, и пользователь перенаправляется на страницу входа.

    Логин (performLogin)

    • Проверяет учетные данные (username, password).
    • При успешной авторизации происходит перенаправление на главную страницу.
    • В случае ошибки выводится сообщение об ошибке.

    2. Работа с классами и расписанием

    Загрузка списка классов (fetchClasses)

    • Отправляется GET-запрос на classes/ для получения списка всех классов.
    • Данные классов сохраняются в состоянии приложения и отображаются на главной странице.
    • Пагинация поддерживается для вывода ограниченного количества классов на странице.

    Детали класса (fetchClassDetails)

    • При переходе по маршруту class/:classId загружается информация о конкретном классе с помощью GET-запроса на classes/{id}/.
    • В случае ошибки отображается соответствующее сообщение.

    Редактирование класса (updateClass)

    • Отправляется PUT-запрос на classes/{id}/ с обновленными данными.
    • В случае успешного обновления происходит редирект обратно на страницу класса.

    3. Управление расписанием

    Загрузка расписания (fetchSchedule)

    • Отправляется GET-запрос на schedule/ для получения расписания всех классов.
    • Расписание для каждого класса отображается на странице с соответствующим классом.

    Редактирование расписания (updateSchedule)

    • Отправляется PUT-запрос на schedule/{id}/ с обновленными данными о расписании.
    • После успешного обновления расписания происходит редирект на страницу с расписанием.

    4. Управление оценками

    Поставить оценку (setGrade)

    • Отправляется POST-запрос на grades/ для установки оценки ученику.
    • Включает параметры: студент, предмет и оценка.
    • Оценка обновляется в системе и отображается на странице класса.

    5. Функции маршрутизации

    Настройка маршрутов

    Для навигации между страницами используется Vue Router. Ниже приведен список маршрутов для различных страниц приложения.

    import { createRouter, createWebHistory } from 'vue-router';
import HomePage from '@/views/HomePage.vue';
import LoginPage from '@/views/LoginPage.vue';
import TeacherDashboard from '@/views/TeacherDashboard.vue';
import ClassDetails from '@/components/ClassDetails.vue';
import ClassList from '@/components/ClassList.vue';

const routes = [
  { path: '/', name: 'home', component: HomePage },
  { path: '/login', name: 'login', component: LoginPage },
  { path: '/teacher-dashboard', name: 'teacherDashboard', component: TeacherDashboard },
  { path: '/class/:classId', name: 'classDetails', component: ClassDetails },
  { path: '/classes', name: 'classes', component: ClassList },
];

const router = createRouter({
  history: createWebHistory(),
  routes
});

export default router;
