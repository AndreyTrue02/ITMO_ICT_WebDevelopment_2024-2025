    Лабораторная работа 3: API для работы с информацией о школе

    В этой лабораторной работе мы создаем API для работы с различной информацией о школе, включая данные о преподавателях, студентах, предметах, расписании и оценках. API реализовано с использованием Django REST Framework.

    Эндпоинты для работы с учителями

    Список и создание учителей

    • GET /school/teachers/ — Получить список учителей
    • POST /school/teachers/ — Создать нового учителя

    Параметры: - user (ID пользователя) — Привязка к пользователю. - subject (массив ID предметов) — Список предметов, которые преподает учитель. - classroom (ID класса) — Привязка к классу, в котором учитель работает.

    Детальная информация о учителе

    • GET /school/teachers/{id}/ — Получить данные об учителе
    • PUT /school/teachers/{id}/ — Редактировать данные учителя
    • DELETE /school/teachers/{id}/ — Удалить учителя

    Эндпоинты для работы с предметами

    Список и создание предметов

    • GET /school/subjects/ — Получить список предметов
    • POST /school/subjects/ — Добавить новый предмет

    Детальная информация о предмете

    • GET /school/subjects/{id}/ — Получить данные о предмете
    • PUT /school/subjects/{id}/ — Редактировать предмет
    • DELETE /school/subjects/{id}/ — Удалить предмет

    Эндпоинты для работы со студентами

    Список и создание студентов

    • GET /school/students/ — Получить список студентов
    • POST /school/students/ — Добавить нового студента

    Параметры: - first_name (строка) — Имя студента - last_name (строка) — Фамилия студента - gender (строка) — Пол (M/F) - school_class (ID класса) — Класс, в котором учится студент

    Детальная информация о студенте

    • GET /school/students/{id}/ — Получить данные о студенте
    • PUT /school/students/{id}/ — Редактировать данные студента
    • DELETE /school/students/{id}/ — Удалить студента

    Эндпоинты для работы с классами

    Список и создание классов

    • GET /school/school-classes/ — Получить список классов
    • POST /school/school-classes/ — Добавить новый класс

    Детальная информация о классе

    • GET /school/school-classes/{id}/ — Получить данные о классе
    • PUT /school/school-classes/{id}/ — Редактировать класс
    • DELETE /school/school-classes/{id}/ — Удалить класс

    Эндпоинты для работы с оценками

    Список и создание оценок

    • GET /school/grades/ — Получить список оценок
    • POST /school/grades/ — Добавить новую оценку

    Параметры: - student (ID студента) — Студент, которому поставлена оценка - subject (ID предмета) — Предмет, по которому выставлена оценка - grade (число) — Оценка - quarter (число) — Четверть (1-4)

    Детальная информация об оценке

    • GET /school/grades/{id}/ — Получить данные об оценке
    • PUT /school/grades/{id}/ — Редактировать оценку
    • DELETE /school/grades/{id}/ — Удалить оценку

    Эндпоинты для работы с расписанием

    Список и создание расписаний

    • GET /school/schedule/ — Получить список расписаний
    • POST /school/schedule/ — Добавить новое расписание

    Параметры: - school_class (ID класса) — Класс - subject (ID предмета) — Предмет - teacher (ID учителя) — Учитель - classroom (ID класса) — Класс - day_of_week (число) — День недели - lesson_number (число) — Номер урока

    Детальная информация о расписании

    • GET /school/schedule/{id}/ — Получить данные о расписании
    • PUT /school/schedule/{id}/ — Редактировать расписание
    • DELETE /school/schedule/{id}/ — Удалить расписание

    Эндпоинты для аутентификации и авторизации

    Авторизация

    • POST /auth/token/login/ — Вход (получить токен)
    • POST /auth/token/logout/ — Выход (удалить токен)

    Данные текущего пользователя

    • GET /account/ — Получить информацию о текущем пользователе

    Личные данные пользователя

    • GET /account/posts/ — Получить список добавленных блюд (в контексте вашей программы: список учеников, расписаний и т. д.)
    • GET /account/comments/ — Получить список комментариев пользователя
    • GET /account/likes/ — Получить список лайков пользователя

    Пагинация

    По умолчанию на странице отображается 6 объектов. Можно изменить количество объектов на странице, добавив параметр ?page_size=X, где X — это максимальное количество элементов на странице (максимум 100).
